# Research corpus

Foundational research that shaped this repository. These are reference documents, not
normative contracts — where they disagree with AGENTS.md, CONTRIBUTING.md, docs/SDD.md,
or an active spec, the repository artifacts win.

- `pipeline-agentic-research.md` — "Slow and Steady": the production-grade agentic ASDLC
  design this repo's pipeline, gates, roles, and charter derive from.
- `rust-service-research.md` — the Rust low-latency classifier implementation guide
  (tokio/tonic discipline, bounded inference, Candle/ModernBERT, build config, caching,
  benchmarking method) that informs the service specs.
